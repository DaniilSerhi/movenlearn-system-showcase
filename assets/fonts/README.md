# Bundled fonts

Unbounded and Source Serif 4 are upstream fonts distributed under the SIL Open Font License 1.1. Their licenses are included beside the binaries.

- [Unbounded source](https://github.com/google/fonts/tree/main/ofl/unbounded)
- [Source Serif 4 source](https://github.com/google/fonts/tree/main/ofl/sourceserif4)

[manifest.json](manifest.json) records the download URL and SHA-256 for each bundled font and license. The source URL uses the upstream main branch; the committed file hash identifies the exact local artifact. Font authorship belongs to the upstream designers and maintainers listed in the licenses.

No font download occurs during document generation.
