# Sample document design

Job: explain a fictional preparation flow in a one-page printable artifact.
Reader: a portfolio reviewer inspecting the document pipeline.
Budget: one A4 page with one dominant heading.

The source of content is [sample-content.json](sample-content.json). This is synthetic process education, not guidance on university eligibility.

| Element | Specification |
| --- | --- |
| Paper / ink | Warm paper #F5F3EF; ink #23262C |
| Secondary ink / rules | #5D636E; #DAD5CC and #EDEAE4 |
| Accent | #EA580C, limited to small labels and one action rule |
| Display / body | Unbounded / Source Serif 4 |
| Page | A4; 17 mm side and top padding |
| Spacing scale | 2, 3, 5, 8 and 12 mm |
| Components | Checklist, comparison table, callout, single action and footer |
| Table | Horizontal rules, no vertical borders or decorative alternating fills |

These requirements follow MoveNLearn's restrained print system. The public HTML and builder contain only synthetic content and a reduced style implementation. Fonts are bundled under upstream licenses.

Acceptance: correct A4 page count, required sections, synthetic marker, footer, embedded fonts, no clipping and a readable visual hierarchy. Structural acceptance is automated; visual judgment is separate.
