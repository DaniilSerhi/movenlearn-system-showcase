# Third-party tools

The showcase distinguishes upstream tools from the workflow built around them.

| Tool | Upstream role | MoveNLearn-specific layer | Included here |
| --- | --- | --- | --- |
| Hallmark | External local design workflow | Requirements, structure and review criteria | Attribution only; no skill source |
| Hallmark PDF | External local document workflow | Print requirements and artifact acceptance | Attribution only; original small public renderer |
| Local voice workflow | External local writing instructions | Factual tone and claim boundaries | Principles only |
| Agent-Reach | Public research tooling | Scoped integration and evidence handoff | Offline synthetic example; no upstream code |
| Exa / mcporter / Jina | Discovery, invocation and reading tools | Query scope and source acceptance | Architectural description only |
| Python | Demo runtime and standard library | Validation, replay, builders and checks | Original demo code |
| Chrome / Chromium | HTML-to-PDF rendering | Page design and render command | Required for PDF regeneration |
| Poppler | PDF inspection and rasterization | Structural acceptance checks | Required for PDF verification |
| Unbounded / Source Serif 4 | Upstream font families | Approved typography pairing | Font binaries and upstream licenses |
| Playwright / Python-Markdown / Pillow / pypdf | Local rendering and artifact inspection | QA during preparation | No runtime dependency |
| AI coding agents | Code and writing assistance | Requirements, iteration and validation | No model or agent runtime |

Public upstream URLs and redistribution rights for the local Hallmark/voice installations were not established for this showcase. Their source is therefore not bundled, and no author is inferred.

Font source details and checksums are recorded in [the font notice](../assets/fonts/README.md). The MIT license covers this repository's original material; fonts retain their own licenses. No production framework is required to run the intake demo.
