# AI-assisted work

The working model uses specialized instructions for review, research/outreach preparation and editorial production. They describe a workflow and its scope; calling an instruction an agent does not make it an autonomous service.

Daniil specifies behavior, context and acceptance criteria. AI coding agents help draft implementations, documentation and tests. Deterministic checks and review then assess the result. The public intake example has no model dependency.

| Activity | AI can assist | Acceptance boundary |
| --- | --- | --- |
| Product implementation | Code and test drafts | Requirements and behavioral checks |
| Research | Query formulation and evidence organization | Read the source; distinguish evidence from inference |
| Editorial | Briefs, drafts and consistency checks | Supported claims and useful prose |
| Documents | HTML and layout iteration | Structural checks and visual inspection |
| Operational processing | Organize a request | A person makes consequential decisions |

Hallmark, Hallmark PDF and a local voice workflow support design and editorial work. They are external local dependencies, not proprietary models developed by MoveNLearn. This repository publishes a compact explanation and original synthetic examples, not those private/local prompts.

Human review is a required gate in the described operating model. The existence of a gate does not by itself prove that every historical artifact passed it.
