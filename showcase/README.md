# Browser case study

Open [the hosted case study](https://daniilserhi.github.io/movenlearn-system-showcase/). The page uses native radio controls and expandable JSON; no JavaScript or backend is required. All case files are synthetic outputs from the existing Python implementation.

The four scenarios correspond, in order, to: Orientation, Request review, Repeat request, Conflicting request. The browser displays recorded results; it does not execute Python. See the [project README](../README.md) for local commands and evidence boundaries.

Before updating a case, regenerate it with the public implementation and update both its JSON file and the embedded JSON in `index.html`. Run the existing project tests and publication checks.
